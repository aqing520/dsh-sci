# 研究记忆：使用、索引与验收边界

研究记忆由 DSH 插件访问本地研究内核，并在 Research Workspace 中检索与审阅。每轮 SDK 任务执行前，内核会检索当前项目的相关记忆，保存检索记录与实际注入摘录，再将有限上下文交给模型。记忆始终作为候选研究材料；可信度或冲突审阅不等于科研结论已经通过核查。

## 工作区操作

在“研究记忆检索”中选择项目，输入关键词并设置可信度或日期范围后搜索。结果展示适用范围、引用、保存时的来源版本/内容摘要及警告。引用记录后续变化会提示重新核查。过期、忽略和已被替代的记忆不会作为有效命中返回；未解决冲突保留提示。

选择项目后点击“重建所选项目记忆索引”。重建使用当前配置重新生成该项目全部记忆的向量，可能产生外部 embedding 请求与费用；搜索的日期、可信度过滤不限制重建语料。界面显示条目数、模型、维度，以及本地基线或语义服务状态。失败保留原始记忆和旧索引。

未启用语义服务时使用中文字符片段与本地哈希向量基线。查询的自动处理仅包括 Unicode NFKC 和空白规范化；插件 API 可显式传入 `rewrittenQuery`。本地查询集的召回成绩不能证明通用语义理解。

## 独立配置 embedding 服务

启动桌面应用前设置 `DSH_SCI_MEMORY_EMBEDDINGS=1`。以下参数可通过应用配置加载的环境值提供（密钥不要提交到仓库）：

| 参数 | 用途与默认行为 |
| --- | --- |
| `DSH_SCI_EMBEDDING_BASE_URL` | 兼容 embeddings API 的 HTTP(S) 基础地址；缺省沿用模型服务地址 |
| `DSH_SCI_EMBEDDING_API_KEY` | 独立密钥；缺省沿用模型服务密钥 |
| `DSH_SCI_EMBEDDING_MODEL` | 模型名称；默认 `text-embedding-3-small` |
| `DSH_SCI_EMBEDDING_VERSION` | 可选服务/模型版本标识；后端版本变化时更新并重建 |
| `DSH_SCI_EMBEDDING_TIMEOUT_MS` | 单次请求超时，默认 15000ms，范围 1000—60000ms |

基础地址不能含用户名、密码、查询串或 fragment。调用失败不会静默改用本地结果；请检查配置后重试。当前 `tokenfans.ai/codex` 的 `/embeddings` 探针返回 HTTP 405，因此真实语义后端验收仍未通过。配置兼容端点后可执行：

```text
npm run build
node scripts/research-memory-live.mjs --out research/validation/w12-memory-live.json
```

探针使用临时合成语料，最多 32 次请求、总时限 120 秒，失败即停。它验证服务和查询集，不替代真实科研记忆的人工质量验收。

## 版本与恢复

V1 索引保留兼容读取；新检索使用 V2 不可变快照，保存语料、向量、模型、提供方、版本、维度和内容哈希。不同模型或维度的向量不混排。更换服务后重建会把选中项目的完整语料转换为目标模型快照，并保留旧索引与原始记忆。搜索可以复用同版本未变化语料的缓存，显式重建会重新调用 embedding。

检索记录绑定精确索引和条目摘要；SDK 注入还绑定任务、轮次及实际截断后的记忆内容。注入最多五条、总 JSON 不超过 12000 字符，保留适用条件、来源和警告。其他项目不会自动注入当前任务。

目前只有同进程内跨内核实例的写入协调，尚无跨进程文件锁；不可变快照也尚无自动垃圾回收。服务在同名模型下静默更换权重不能自动识别，应设置版本标识并重建。
